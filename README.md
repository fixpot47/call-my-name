# Call My Name

A tiny client-side Fabric mod that plays a Minecraft pling sound when another player mentions your username in chat.

## Features

- Plays a short `pling` when your username is mentioned in player chat
- Case-insensitive username matching
- Ignores your own messages
- No keybinds, menus, commands, or configuration
- Client-side only — servers and other players do not need the mod

## Requirements

- Minecraft 26.2
- Fabric Loader
- Fabric API
- Java 25
